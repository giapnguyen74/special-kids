# Special Kids

Learning games for teens with intellectual developmental disorder (IDD). English + Vietnamese.

## Layout (Flutter workspace / monorepo)

```
apps/
  special_kids/        Hub app: Snack Beats + Sing & Say + upcoming games   (com.specialkids.special_kids)
  snack_beats/         Standalone Snack Beats app                             (com.specialkids.snack_beats)
packages/
  sk_core/             Shared core used by every app and game
  snack_beats_game/    Snack Beats game module (used by both apps)
prototype/             v1 web prototype (plain JS) for quick idea tests
tool/                  dev scripts (web screenshots, FPS probe, no-cache web server)
```

One `pubspec.yaml` workspace at the root resolves all members together.

```bash
flutter pub get                                   # at repo root, once
cd apps/snack_beats  && flutter run               # standalone Snack Beats
cd apps/special_kids && flutter run               # hub app
cd packages/snack_beats_game && flutter test      # tests (also in apps/*)
flutter build apk --release                       # inside an app folder
```

QA flags: `--dart-define=SK_SEED=7` (repeatable board), `--dart-define=SK_SHOWCASE=true` (one of each special in row 1),
`--dart-define=SK_LEVEL=n` (start at level n).

## Snack Beats levels

200 levels live in `packages/snack_beats_game/lib/snack_beats/levels_data.g.dart`, generated by
`dart run tool/generate_levels.dart` (in `packages/snack_beats_game`). Each level = board shape (12 shapes, with holes)
+ obstacles (ice 1–2 layers, walls, rocks, mud) + fruit goals. Moves are calibrated by a play-test robot
(half goal-aware, half random moves): moves = 80th percentile of robot games + 2, so most children can win.
Chapters of 20 levels introduce one thing at a time; every 5th level is an easy one.

## packages/sk_core

```
core/content/     foods, sentences, songs, languages (EN/VI)
core/progress/    child profile + on-device event log
core/initiation/  StartCueButton: waits for the child, glow -> hand cue, help fades
core/sentence/    SentenceBuilder: word tiles with fading hints
core/speech/      text-to-speech
core/audio/       marimba notes, songs, chimes (assets/audio/notes, made by tool/gen_notes.dart)
core/session/     play-time tracking + parent-gated break screen
core/rewards/     shared music collection
core/ui/          theme, kid-friendly widgets, effects
parents/          parent dashboard (press and hold to open)
l10n/             UI strings (app_en.arb, app_vi.arb) — run `flutter gen-l10n` in packages/sk_core after editing
testing/          fakes for widget tests
```

The microphone meter lives only in `apps/special_kids/lib/voice/` (Sing & Say), so the standalone
Snack Beats app ships without microphone code or permission.

## Skill set (lessons embedded in games)

`packages/sk_core/lib/core/skills/skills.dart`:
- **SkillModule** = a reusable short lesson (`ask_treat`, `ask_help`, `counting`; lesson screens in `core/lessons/`). It pops a `SkillOutcome`.
- **GameSkillSpec** = what a game offers: its **slots** (`afterLevel`, `outOfMoves`), which modules fit each slot, and defaults.
- **SkillEngine** = picks the next enabled module for a slot (round-robin), runs it, logs a `skill` event.
- The **parent** turns modules on/off per game and slot, and sets how often the after-level lesson appears
  (Parent area → Lessons). "Suggest" fills this from the child's profile (speaking / reading / counting levels).
- One child per device: the profile (`profile.default`) holds who the child is, their lesson settings and progress.

## Adding a game

1. Create a package `packages/<game>_game/` (depends on `sk_core`), or a folder in the hub app.
2. Use `StartCueButton` for every "start" moment, log with `eventLogProvider`, reward via `profileProvider`.
   Declare a `GameSkillSpec` and call `skillEngineProvider.run(...)` at its slots; add the spec to the app's `gameSkillSpecsProvider` override.
3. Register it in `apps/special_kids/lib/games/game_registry.dart`.
4. Optional standalone app: `flutter create apps/<game>`, add `resolution: workspace`, point `home:` at the game's home screen.

## Notes

- Vietnamese song lyrics need review by a native-speaking music teacher (tone vs. melody) before release.
- Web builds are previews; phone/tablet apps are the product (faster, real microphone).

## Design rules

No ads, no purchases, no lives, no failure screens. Never auto-advance (initiation training).
Help always fades. Teen-appropriate look. All data stays on the device.
